# 스크린샷 촬영 가이드

Chrome Web Store 제출 기준: **1280x800 또는 640x400** (PNG/JPEG)
최소 1장 필수, 최대 5장 권장

---

## 권장 스크린샷 구성

| 순서 | 내용 | 촬영 방법 |
|------|------|----------|
| 1 | 유튜브 영상 위 플로팅 컨트롤러 표시 | YouTube 영상 재생 후 오버레이가 보이도록 캡처 |
| 2 | 팝업 UI (배속 입력 + 프리셋) | 확장 아이콘 클릭 후 팝업 캡처 |
| 3 | Netflix 배속 적용 화면 | Netflix 콘텐츠 재생 + 오버레이 표시 |
| 4 | 전체화면에서 오버레이 표시 | 전체화면 모드에서 오버레이가 보이는 상태 캡처 |

---

## 촬영 팁

- Chrome DevTools → Device Toolbar → 1280x800 해상도 설정 후 캡처
- 오버레이가 잘 보이도록 마우스를 오버레이 위에 올린 상태에서 캡처
- 배속이 1.5x, 2.0x 등 기본값이 아닌 상태로 캡처하면 기능 어필에 효과적

---

## 스토어 아이콘

- 128x128 PNG 형식 필요
- `icons/icon128.png` 파일을 교체하거나 별도 제작
